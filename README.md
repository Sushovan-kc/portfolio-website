 # Sushovan Kc Portfolio

 Personal portfolio for Sushovan Kc, an AI and machine learning engineer focused on computer vision, medical imaging, and production-ready applications.

 The site is a single-page React experience with responsive navigation, light and dark themes, interactive particle backgrounds, project showcases, and direct resume download.

 ## Stack

 - React 19 and Vite
 - Tailwind CSS 4
 - React Router DOM
 - Framer Motion
 - Lucide React
 - Canvas-based Aether Flow background for light mode
 - Interactive particle field for dark mode
 - Oxlint

 ## Requirements

 - Node.js 20 or newer
 - npm 10 or newer

 ## Local Development

 From this folder:

 ```bash
 npm install
 npm run dev
 ```

 Open the local URL printed by Vite, usually `http://localhost:5173`.

 ## Commands

 ```bash
 npm run dev       # Start the development server
 npm run lint      # Run Oxlint
 npm run build     # Create a production build in dist/
 npm run preview   # Preview the production build locally
 ```

 ## Updating Content

 - Edit project, skill, education, and navigation data in `src/data/portfolio.js`.
 - Replace project images in `public/images/projects/`.
 - Replace `public/resume.pdf` to update the downloadable resume.
 - Update social and contact links in the relevant section components.

 ## Upload To GitHub

 Create an empty repository on GitHub, then run these commands from this `portfolio` folder:

 ```bash
 git init
 git add .
 git commit -m "Initial portfolio setup"
 git branch -M main
 git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
 git push -u origin main
 ```

 Before pushing, review the staged files:

 ```bash
 git status
 git diff --cached --stat
 ```

 The included `.gitignore` excludes `node_modules`, `dist`, local environment files, logs, caches, editor settings, and operating-system files. Source code, assets, `public/resume.pdf`, `package.json`, and `package-lock.json` remain uploadable.

 ## Deployment

 The production output is generated with:

 ```bash
 npm run build
 ```

 For GitHub Pages, deploy the generated `dist/` folder through a GitHub Actions workflow or a static hosting provider. Do not commit `dist/`; it is intentionally ignored and should be generated by CI.
